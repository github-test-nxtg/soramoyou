# そらもよう

開いたらすぐ天気がわかる、ビルド不要のシンプルな天気Webアプリです。

## 機能

- 現在の天気（気温・体感・湿度・風速・降水確率）
- 24時間の気温カーブと降水確率
- 7日間の予報
- 都市名検索（日本語・ローマ字）と現在地表示
- 天気と昼夜に合わせて背景の空の色が変化
- 最後に見た場所を記憶（localStorage）

## 使い方

`index.html` をブラウザで開くだけで動きます。ローカルサーバーで動かす場合は:

```sh
npx serve .
# または
python3 -m http.server 8000
```

外部APIに接続できない環境ではデモデータが表示されます。

## データ

気象データと都市検索は [Open-Meteo](https://open-meteo.com/) を利用しています（APIキー不要）。
商用利用の際は Open-Meteo の利用規約を確認してください。
